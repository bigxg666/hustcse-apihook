# HUSTCSE-APIHOOK

## 介绍

2024春 HUST CSE 软件安全课程设计 基于 API HOOK 的软件行为分析系统 Release v1.1

仓库地址：[HUSTCSE-APIHOOK](https://gitee.com/cselyp/hustcse-apihook)

## 使用说明

### GUI

+ dll
  + 该文件夹用于存放自定义的API监控Dll：hookDll.dll
+ GUI.exe
  + 请右键单击该程序，使用管理员模式打开

### socket_test

+ networktest_client.exe
  + 网络操作测试程序的客户端
+ networktest_server.exe
  + 网络操作测试程序的服务端

### testCode

+ testCode.exe
  + 包含多项功能的测试程序

### FCInject.exe

+ 旧的注射器程序

### ReadLog.exe

+ 旧的日志信息显示程序
